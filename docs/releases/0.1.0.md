# Body Harvest: Recompiled 0.1.0

**This is a very early build and it is still very untested.** Only the start of the game has been
played: boot, the menus, a new game and the first part of Greece on foot, including walking into and
out of a house. Everything after that needs a lot of testing now. Please report crashes, broken
scenes, and graphics, audio, save or controller problems.

Added:

- First release: a native Windows and Linux port of Body Harvest (USA)
- Widescreen at your window's shape: a genuinely wider view, with the game's culling widened to match,
  indoors included
- HUD anchored to the screen edges in widescreen: radar, health and alien bars, weapon panel
- High frame rate through interpolation; the game keeps its own 20 fps logic
- Launcher with graphics, sound and controls settings, remapping and a mods tab
- Keyboard and controller support; the keyboard always plays, pads join as they are plugged in
- EEPROM saves and the Rumble Pak, with a rumble strength setting
- F1 debug menu with a live HUD editor

Known bugs:

- Other HUD elements (dialogue boxes, scanner text) are not anchored to the screen edges yet

Not tested:

- Vehicles, the levels after Greece and level changes
- Cutscenes and camera cuts with high frame rate
- Continuing from a saved game
- Audio pitch against the original
- Displays above 60 Hz, and cost on low-power GPUs
- Linux on real hardware (only run under WSL)

You need your own dump of **Body Harvest (USA)**. Windows: unzip and run
`body-harvest-recomp.exe`. Linux: extract and run `./body-harvest-recomp.sh`.
